# MAGSCAN ULTIMATE 3D — نسخه پایه اندروید

این پروژه از صفر با Kotlin و Jetpack Compose ساخته شده است.

## امکانات موجود در این نسخه
- رابط فارسی با تم تیره و رنگ فیروزه‌ای
- صفحه خانه، اسکن سه‌بعدی نمایشی، مدیریت سنسورها و تاریخچه
- درخواست مجوزهای بلوتوث و جست‌وجوی دستگاه‌های BLE
- نمایش دستگاه‌های BLE پیدا شده

## مواردی که هنوز کامل نیستند
این نسخه هنوز به ESP32 وصل نمی‌شود تا داده سنسورها را بخواند؛ جست‌وجوی BLE با اتصال و دریافت داده فرق دارد.
برای پیاده‌سازی اتصال و داده واقعی باید پروتکل ESP32 مشخص شود: BLE یا Bluetooth Classic، نام سرویس/Characteristic یا قالب پیام سریال.
خواندن EMS-100 نیز تا مشخص‌شدن ولتاژ خروجی و مدار ADC/محافظت، فعال نشده است.
نمایش سه‌بعدی فعلی فقط نمای شبکه‌ای نمونه است و داده زیرزمینی واقعی نشان نمی‌دهد.

## ساخت APK با GitHub Actions
1. همه فایل‌های این پوشه را در ریشه یک مخزن GitHub بارگذاری کن.
2. فایل `.github/workflows/build.yml` را هم بارگذاری کن.
3. در GitHub وارد تب Actions شو و اجرای workflow را باز کن.
4. از پایین صفحه، Artifact با نام `MAGSCAN-Android-APK` را دانلود کن.
5. ZIP دانلودشده را باز کن؛ فایل `app-debug.apk` داخل آن است.

نیازمندی ساخت: JDK 17 و Gradle 8.7 (workflow خودش Gradle را آماده می‌کند).
